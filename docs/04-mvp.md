## 1. 目的・背景
- 解決したい課題：小学生の理系科目への興味の向上
- 作る理由（なぜ今か）：
- 成功の定義（MVP の目標）：
  - デモで「撮影 → 囲む → 問い → 予想 → 答え合わせ → 条件変更 → 保存」の動線が最後まで通ること

## 2. 対象ユーザー
- 主な利用者：小学生中心
- 利用シーン：お出かけをしているときや、外で遊んでいるときなど

## 3. スコープ
**やること（In Scope）**
- 4章の F-01〜F-11（撮影から保存までの動線、認証、プロフィール、安全対策）

**MVP に入れるか未決のもの**
- 収集要素（モチベーション付け。前版では優先度 Should）：【未決】
- ミッション（今日のお題）：【未決】
- 匿名で他の人の問題を見る：【未決】
- プロフィールの切り替え（兄弟で1台）：【未決】
- 起動時・撮影時の注意表示：【未決】

**やらないこと（Out of Scope ＝ MVP 以降に回すもの）**
- 位置情報と地図でのアーカイブ表示（どこで問題に答えたのか、その写真・問題・回答を地図上で見られるようにする）
- 問題のレベルと、解答履歴による難易度調整（最初から難しすぎる問いが出ないようにし、同じシチュエーションを撮ったときに以前より高度な問いが出るようにする）
- 「別のもので試す」（LLM に派生の問いを出させる）
- 送信前に顔を自動でぼかす（他人の顔が映っている場合のモザイク処理）
- モデレーション API による画像と生成文のチェック
- 公開する場合の1日の利用回数制限
