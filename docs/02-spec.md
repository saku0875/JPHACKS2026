# 仕様書

## ホーム画面
-ログインボタン、写真を撮る、アプリの概要、アーカイブ
-余裕があればfigma等で画面設計をする

## 認証機能
-アーカイブ機能のみに使う
　・集める情報:ユーザ名、パスワード、id、(年齢)

## カメラ機能
-問いを見つけるための写真を撮る(気に入らなかったら再撮影)

## 問を見つける
-囲ませる→範囲の確認(ダメならもう一度囲ませる)
-範囲を確定したら→レベル選択→写真を切り取る(裏側で処理)→OpenAIのAPIに送る
-確定したらレベル選択と並列で画像の処理をする(OpenCV)

## 問を出す
-複数候補(2~3個)を選択させる(再抽選はなし)
-問題を解かせる
-入力フォームを用意して入力して答えさせる
-スライドと入力をいい塩梅で使い分ける
-この時点で問題と一緒に答えも出させる(ただし表には出さない)
-問題を出す形式をパターン化させて、出題時にどの答え合わせの画面を出すかをパターン化させる

## 答え合わせ
-隠していた答えを出す
-アニメーションを用いて単調にならないように
-あらかじめ複数種類画面(テンプレート)を用意する
-余裕があればfigma等で画面設計をする
