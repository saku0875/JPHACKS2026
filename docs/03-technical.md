# 技術仕様

企画書（`docs/01-overview.md`）と課題の決定（`docs/06-overview-issues.md`）のうち、技術に関わるものをまとめる。

## 決まっていること
- LLMの出力はJSONで構造化する（問い・式・変数・単位・正解・解説・出典）。条件変更のスライダーは、この式と変数を使ってアプリ側で再計算する
- LLMに送る画像は「切り抜き＋全体」か「全体＋囲んだ座標」のうち、認識しやすい方を実装時に比較して決める
- 応答待ちを短くするため、撮影直後から裏でLLM呼び出しを始める（先読み生成）
- 通信はオンライン必須（通信できないときはエラーを表示する）
- アーカイブはクラウドに保存する（写真は切り抜きのみ）
- 認証は自前で作る（サインアップ〜パスワードリセット）
- APIの利用回数はハッカソン期間中は制限しない
