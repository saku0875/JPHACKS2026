# 発表デモ版

`fk_2601` をコピーした、発表デモ専用の版です。本体には戻しません。

- どんな写真を とっても、AI に送らず「ペットボトル」と して、用意した問いを3つ返します
  - 500mL を毎日のむと、25m プールをのみきるのに何年？（約1973年）
  - キャップを毎日2ばい あつめると、30日目は何こ？（536,870,912こ）
  - たんさんのペットボトルの そこが でこぼこなのは どうして？
- 「じぶんで かく」は使えません（ことわりの メッセージが出ます）
- Firebase なし・API キーなしで動きます（`.env.local`）。データはブラウザに保存されます

変えたところ：`src/server/llm/generate.ts`（AI を呼ばない）、`src/server/llm/builtin.ts` の末尾（`PET_BOTTLE`）

## うごかしかた
```
npm run dev
```
スマホで カメラを使うときは HTTPS が必要です（`npx next dev --experimental-https` など）。
