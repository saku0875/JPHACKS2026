## 製品概要
### 背景（製品開発のきっかけ、課題等）
日本では理系に進む人が少なく、その手前には「理科・算数・情報に興味を持つ子どもが少ない」という課題があります。
いつもの景色の中には、数や理科のふしぎがたくさんかくれていますが、子どもがそれに気づく機会はあまりありません。
既存のサービス（画像検索・チャット AI・図鑑アプリ）は「答え」を出してくれますが、「問い」を見つけるのは人間の側です。

### 製品説明（具体的な製品の説明）
小学生向けの、日常の風景から理系の「はてな（問い）」を見つけるアプリです。

1. 写真を撮る（アルバムからも選べる）
2. 気になる部分を、指でぐるっと囲む
3. 囲んだ部分から、AI が「予想がはずれて、おどろく」問いを3つ作る（自分で問いを書くこともできる）
4. まず直感で予想する（せーの！）
5. 答えと予想のズレを、数直線・倍率・身近なものへの言いかえで見せる（「よそうの やく7ばい！」）
6. ナビ（キャラクター）が、答えまでの考えかたを手順で解説する（なぞとき）
7. 条件をスライダーで変えて、答えがどう変わるかを確かめる（もしも…？）
8. 写真・問い・予想・結果を「はてなずかん」に残し、分類ごとのスタンプと称号を集める

### 特長
#### 1. 問いを見つけるのは子ども自身
写真を「囲む」操作をしないと問いは出ません。どこに注目するかを自分で決めることで、受け身にならずに「なんだろう？」を自分のものにできます。

#### 2. 直感がはずれる「おどろき」が入口
答えを先に見せず、必ず予想してから答えを見せます。AI には「多くの子どもの予想が5倍以上ずれる問い」「思いこみがひっくり返る問い」を作らせ、ただの計算問題は出しません（例：ガチャ10種類をぜんぶそろえる平均は約29回、氷がとけてもコップの水の高さは変わらない）。

#### 3. 子どもが使う前提の、正確さと安全
答えは AI に計算させず、AI が出した式をアプリが安全に計算します（AI の答えと5%以上ずれる問いは出さない）。学年に合わせた漢字・ふりがな・単位・予想の入力方法、顔を撮らない注意、送る画像は囲んだ部分だけ、など子ども向けの安全を整えています。

### 解決出来ること
- 子どもが、いつもの景色の中に理科・算数・情報のふしぎがあることに気づける
- 「予想がはずれた」おどろきから、自分で考えたり調べたりするきっかけが生まれる
- 学年・学習の進み具合に合わせた問いで、無理なく続けられる

### 今後の展望
- 撮った場所を地図で見返せる「はてなマップ」（位置は本人のずかんだけで使う）
- 兄弟で1台を使うためのプロフィールの切り替え
- 画像と生成文のチェック（モデレーション）と、匿名公開の安全な運用
- 送る前に顔を自動でぼかす
- 学習の進み具合の測り方を、正答の傾向なども使って改善する

### 注力したこと（こだわり等）
* 「答え」ではなく「問い」を出す体験の設計（囲む → 予想 → ズレ → なぞとき → もしも の流れ）
* AI が間違えた答えを子どもが覚えないよう、計算はすべてコードで行い、AI の答えと照らし合わせて検算する
* 小学生が読めること：22px 以上の漢字にはふりがな、小さい文字はひらがな、むずかしいことばは やさしいことばに言いかえる
* AI が使えないとき・会場で撮影できないときでも、見本の絵で最後まで試せる

## 開発技術
### 活用した技術
#### API・データ
* Claude API（画像入力・構造化出力（JSON）。本番は Claude Sonnet 5.5）
* Firebase Authentication（ユーザー名とパスワードでのログイン。メールアドレスは集めない）
* Cloud Firestore（プロフィール・はてなずかん・匿名公開。本人だけが読み書きできるルール）

#### フレームワーク・ライブラリ・モジュール
* Next.js（App Router）・React・TypeScript
* Tailwind CSS
* math.js（AI が出した式の安全な計算）
* Zod（AI の出力の形の検証）
* Vercel（公開。関数は東京リージョン）

#### デバイス
* スマートフォン（iOS Safari・Android Chrome）。Web アプリなので、URL を開くだけで使えます

### 独自技術
#### ハッカソンで開発した独自機能・技術
* 囲んだ部分だけを切り抜いて AI に送る仕組み（写真の向きを直し、位置情報などの情報を消して縮小）：[`src/components/LassoPicker.tsx`](src/components/LassoPicker.tsx)・[`src/lib/image.ts`](src/lib/image.ts)
* 「予想がはずれて、おどろく」問いを作るプロンプト：[`src/server/llm/prompts.ts`](src/server/llm/prompts.ts)
* AI の式を安全に計算し、AI の答えと検算して、合わない問いを出さない仕組み（確率・場合の数の関数つき）：[`src/lib/calc.ts`](src/lib/calc.ts)・[`src/server/llm/validate.ts`](src/server/llm/validate.ts)
* 予想とのズレを見せる数直線と、条件を変えたときの変化の見せ方：[`src/components/NumberLine.tsx`](src/components/NumberLine.tsx)・[`src/components/ConditionSliders.tsx`](src/components/ConditionSliders.tsx)
* ふりがなの記法と、小さい文字のひらがな化・単位の読み：[`src/lib/ruby.ts`](src/lib/ruby.ts)
* ライブラリを使わない ID トークンの確認（ログインした人だけが AI を呼べる）：[`src/server/auth.ts`](src/server/auth.ts)
